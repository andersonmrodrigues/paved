# Complete implementation

Find the affected code, callers and existing helpers before introducing abstractions.
Load selected adapter knowledge for technology-specific work. Test clear expected behavior
before implementation and confirm the intended failure, not a tooling error.
Keep validation, failure handling and accessibility intact.

Activate `feature-development` for implementation, delegation and evidence procedures;
use `task-specification` when acceptance claims need refinement. Their existing contracts
remain in effect when activated; this playbook does not waive plan approvals.
Pick only relevant verification levels and report missing checks.
