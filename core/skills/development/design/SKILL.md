# Design
## When to use
Interface design or prototyping.
## Required context
User goal and constraints.
## Preconditions
Separate experiments from production.
## Procedure
Compare approaches and proof options. Obtain product decisions.
Activate `frontend-design` or `prototyping` only as needed.
## Tools
Project preview and checks.
## Rules
Keep accessibility and scope intact.
## Verification
Check the relevant interaction.
## Evidence
Observed behavior and experiment limits.
## Completion criteria
The design question has an answer.
## Failure modes
Unverified feasibility: label it.
