# Setup
## When to use
Installation or maintenance.
## Required context
Installation state.
## Preconditions
Respect ownership and permissions.
## Procedure
Run `paved doctor --quick`. Use supported initialization, update or refresh actions;
inspect help and outcomes. Activate `repository-onboarding` for detailed setup.
## Tools
Installed Paved launcher.
## Rules
Do not overwrite local work.
## Verification
Recheck maintenance state.
## Evidence
Report completed writes and gaps.
## Completion criteria
The requested maintenance is verified.
## Failure modes
Ambiguous inference: ask once.
