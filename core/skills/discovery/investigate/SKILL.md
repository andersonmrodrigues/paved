# Investigate
## When to use
Repository orientation or a question.
## Required context
The relevant entry point.
## Preconditions
No implementation is requested.
## Procedure
Follow one trace, inspect sources, distinguish observations from inferences.
Activate `context-discovery` for broad orientation.
## Tools
Read-only search and inspection.
## Rules
Do not fill unknowns with guesses.
## Verification
Cross-check important claims.
## Evidence
Source paths and limitations.
## Completion criteria
The question has a grounded answer.
## Failure modes
Missing source: report uncertainty.
