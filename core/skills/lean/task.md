# Task

Use for a handoff or a mid-flow request. If it serves the same goal, incorporate it;
if a task handoff is in use, record the note with `paved task note <slug> <text>`.
If it changes the goal, ask one focused question. Existing workflow approvals remain
in force; a task note does not amend or approve a workflow plan.

Use `paved task start`, `note`, `resume`, and `done` as supported by their help.
Keep goal, state, decisions, notes, evidence and next step concise. Do not place
credentials or sensitive data in a handoff.
