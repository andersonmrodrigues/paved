# Feature

Use for behavior changes. Describe observable outcomes and scope, inspect the affected
code and relevant rules, then make the smallest complete change. For known behavior,
write a failing targeted test first; confirm it fails for the intended reason and
make it pass. Load selected adapter guidance for technology-specific work. Preserve
validation and failure handling. Verify affected behavior and report gaps.
