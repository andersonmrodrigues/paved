# Design

Use for a user-facing design or feasibility experiment. Clarify the user goal and
constraints, compare suitable approaches and identify how to verify the result.
Distinguish disposable prototypes from production changes. Obtain product decisions
from the human; implement only within the requested scope.

Details: [frontend design](../development/frontend-design/SKILL.md) and
[prototyping](../development/prototyping/SKILL.md).
