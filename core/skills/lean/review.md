# Review

Use for a change review. Inspect the diff, relevant contracts and proof. `paved review
plan` recommends scope; it does not itself run reviewers. Scale independent review to
the change and host capabilities. Verify findings with a test, command or specific
code evidence; keep unproven concerns as notes. Fix proven issues and rerun checks.
