# Paved lean router

Use this advisory index for the task; load one playbook and only the references it needs.
It does not replace active workflow gates, host permissions, or project instructions.

| Request | Playbook |
|---|---|
| Initialize or maintain Paved | [setup](setup.md) |
| Add or change behavior | [feature](feature.md) |
| Diagnose and fix a defect | [bug](bug.md) |
| Restructure without behavior change | [refactor](refactor.md) |
| Answer a repository question | [investigate](investigate.md) |
| Prove a result | [verify](verify.md) |
| Inspect a change | [review](review.md) |
| Deliver a change | [ship](ship.md) |
| Capture a lesson | [reflect](reflect.md) |
| Manage handoff or a mid-flow request | [task](task.md) |
| Explore a user-facing design | [design](design.md) |

State the goal and smallest change briefly. For ambiguity that is not a product decision,
state an assumption and proceed. Ask when rules conflict or the decision belongs to the
human. Read only relevant context. Keep small tasks direct; delegate independent work
only when useful, and integrate results yourself. Run relevant checks and report proof
and gaps. Respect requests that are investigation-only or planning-only.
