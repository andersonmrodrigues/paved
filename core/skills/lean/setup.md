# Setup

Use for initialization, updates, or stale project context. Run `paved doctor --quick`
for a read-only diagnosis. For an uninitialized repository, inspect initialization
options and use `paved init` when authorized. For an outdated installation, inspect
and use `paved update` when authorized. Neither operation is represented here as
automatic or noninteractive. For stale context, inspect the affected area and use the
available refresh or generator workflow; do not claim a refresh command exists.
Ask when inference needs a product choice.

[harness refinement](../testing/harness-refinement/SKILL.md).
