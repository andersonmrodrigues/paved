# Bug

Use for a defect. Reproduce the symptom, inspect evidence and identify a cause before
changing code. Add a regression test that fails for the defect; fix the cause, then
rerun it and affected checks. If reproduction or proof is unavailable, report the gap.

Details: [bug investigation](../debugging/bug-investigation/SKILL.md),
[root cause](../debugging/root-cause-analysis/SKILL.md),
[runtime debugging](../debugging/runtime-debugging/SKILL.md), and
[regression testing](../testing/regression-testing/SKILL.md).
