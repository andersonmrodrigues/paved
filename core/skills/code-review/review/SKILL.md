# Review
## When to use
Independent change inspection.
## Required context
Diff, contracts and proof.
## Preconditions
Reviewers do not edit.
## Procedure
Use `paved review plan` for recommended scope; inspect relevant paths.
Load specialist lenses on demand. Prove findings; retain unproven concerns as notes.
## Tools
Diff and targeted checks.
## Rules
Do not promise unavailable reviewers.
## Verification
Reproduce blocking defects.
## Evidence
Commands or specific code excerpts.
## Completion criteria
Findings are actionable and grounded.
## Failure modes
Missing independence: disclose it.
