# Live handoff

Inspect `paved task --help` for supported start, note, resume and done inputs.
Keep Goal, State, Decisions, Mid-flow notes, Evidence and Next step current.
On resume, compare the handoff with changed paths before acting. Record same-goal work
without adding a new approval ritual; active workflow approval requirements still apply.
If the goal changes, ask a single focused question with a recommended direction.
Never present a task note as an amendment or approval of an existing workflow plan.
