# Task
## When to use
Task continuity or scope notes.
## Required context
Current goal and state.
## Preconditions
A note does not approve a workflow plan.
## Procedure
A mid-flow request serving the same goal becomes a note.
For a changed goal, ask once. Use supported `paved task` operations.
## Tools
Task handoff commands.
## Rules
Keep sensitive data out.
## Verification
Read back saved state.
## Evidence
Keep proof and gaps with the task.
## Completion criteria
Next step is unambiguous.
## Failure modes
Stale handoff: compare with the checkout.
