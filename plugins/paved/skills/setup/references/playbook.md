# Maintenance options

For an uninitialized repository, inspect `paved init --help` and initialize when authorized.
For outdated state, inspect `paved update --help` and use the supported update path.
Neither diagnosis implies automatic writes or that a noninteractive flag exists.
For stale context, use a supported refresh or generator procedure for the affected area;
report unsupported operations instead of inventing commands.

Activate `repository-onboarding` for stack and verification discovery; activate
`harness-refinement` for bounded comparisons of alternative harness configurations.
Preserve generated-file ownership and transactional safeguards. Confirm actual state
after a write and report host reload requirements separately.
